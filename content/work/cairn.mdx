## Key decisions

<Decisions>
  <Decision n="01" title="A dedicated deployment per venue">
    Each venue owns its data and infrastructure, while every launch reuses the same platform instead of rebuilding it.
  </Decision>
  <Decision n="02" title="CMS adapters, not a new CMS">
    Contentful and Contentstack adapters map to one shared content model, so venues keep the tools their teams already know.
  </Decision>
  <Decision n="03" title="Scout on Eve, sharing Conduit">
    The concierge sells through the same commerce layer as the website, so answers and checkout never drift apart.
  </Decision>
